# MTF073 Computational Fluid Dynamics: The Finite Volume Method

A course taught by Håkan Nilsson, at Chalmers University of Technology

This project contains OpenFOAM tutorials for the three computer tasks of the course. They show how to install and use OpenFOAM, and how to set up and run the tasks in OpenFOAM, so that the results can be compared with those of your own Python codes.

Go through the files in the order of their numbers.

It is easiest to read the `.md` files on GitHub, at https://github.com/drhakannilsson/MTF073_CFD_Tasks, where they are shown with formatting, tables and images.

## Get the files

In the Ubuntu terminal (see [01_Install_OpenFOAM-v2606_WSL.md](01_Install_OpenFOAM-v2606_WSL.md)), download the whole project to your home directory:

```
cd
git clone https://github.com/drhakannilsson/MTF073_CFD_Tasks.git
```

Get the latest version later with `git pull` in `~/MTF073_CFD_Tasks`.
